# Personal Portfolio

## Project Description
This project is a static HTML Personal Portfolio Page served using the Bonezegei Scripting Language HTTP Web Server framework. It showcases my profile, skills, and projects.

**Tech Stack:** HTML, CSS, Bonezegei Scripting Language, GitHub Codespaces.

## Setup & Execution Steps
1. Forked the reference repository and ensured it is Public:
    ```bash
    https://github.com/msuiit-ph/BSL_HTTP_and_WebSocket 
2. Included an official MIT License file and a README.md file.
3. Opened the repository in GitHub Codespaces.
4. Modify the contents in `public/index.html` to include personal details (Name, Summary, Skills, Projects, Contact).
5. Opened the terminal and installed dependencies:
   ```bash
   bzg install   
6. Launching the web page:
   ```bash 
   bzg run
7. Open the port to view the page in the browser.
